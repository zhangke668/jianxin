# 阶段（五关第 4 步"认知"里的"为什么偏偏是现在"）

> **这是经验框架，不是研究结论。** 它来自作者对创业者的长期观察（作者把它叫作"生态位"理论）。用来帮用户理解"为什么偏偏是现在"，**不要对用户说成规律**，也不要说"研究表明"。
>
> **信息不够就跳过这一层。** 判断阶段至少需要知道两件事：他现在的状态，和他最早是怎么做起来的。没有这两样，不要编。

## 核心观察

上一阶段让你成功的优点，到了下一阶段可能变成限制。

- 从 0 到 1，常常靠加法：多试、多干，问的是"我要什么"。
- 从 1 到 10，常常靠减法：减项目、减亲力亲为，问的是"我不要什么"。

"减法"只适用于规模化类的问题。定价、合伙、转型这类问题，不要硬套。

---

| 阶段 | 判断信号 | 上一阶段的优点 → 现在的限制 |
|---|---|---|
| **起步**（入局者）：还没稳定赚到钱，或者刚跑通第一单 | 一直在找方向、调研、买课；"我还没准备好" | 谨慎、多看看 → 用准备代替开始 |
| **反复起步**（0-1 循环）：跑通过两个以上项目，每个赚一点就换 | "下一个做什么？""想放弃又舍不得，不放弃又太累" | 什么都敢试、起盘快 → 每个项目都停在起步阶段 |
| **单人爬坡**（借势者）：一个项目收入稳定，但几乎全靠自己 | 累，不敢招人，不敢涨价，觉得员工不行 | 亲力亲为、能省则省、自己最熟练 → 收入被自己的时间封顶 |
| **开始有势能**（成势者）：有代表作，机会主动找上门，开始有团队 | 机会太多不知道选哪个；守着赢过的打法；扩张失衡（流量多、交付跟不上） | 抓住过红利、打法被验证过 → 守着旧路，或者把红利当成能力 |
| **有基本盘**（布局者）：收入稳定，赚到了 | 没劲，目标越定越大，停不下来，"赚钱到底为了什么" | 永远往前冲、目标驱动 → 终点一直往后退 |

## 两种最常见的"放不大"

用户问"为什么跑通了却放不大"时，先看他是哪一种，很多人两种都占。

| | 换得太勤 | 守得太死 |
|---|---|---|
| 表现 | 每个项目赚一点就换 | 什么都自己干，收入到了一个数就上不去 |
| 在加什么 | 加项目 | 加自己的时间 |
| 可以减什么 | 减项目，只留一个 | 减自己，交出最不该自己干的那几个小时 |
